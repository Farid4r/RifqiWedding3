# Data

- `invitation.js` adalah sumber resmi informasi pasangan, riwayat akad, jadwal
  resepsi, lokasi, dan status data section.
- `assets.js` mencatat direktori aset publik serta aset yang benar-benar tersedia.

Perbarui detail acara hanya di konfigurasi pusat ini. Nama orang tua, nama venue,
tautan maps, foto, musik, RSVP, dan hadiah tetap kosong sampai informasinya
diberikan pemilik proyek.
